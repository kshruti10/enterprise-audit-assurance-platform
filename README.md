# Enterprise Audit & Assurance Platform

An enterprise-grade Audit & Assurance platform built using
**.NET Core**, **Angular 11**, and **Microsoft Azure**.

> This repository represents a sanitized version of a real-world enterprise system.
> No proprietary or client-specific information is included.

---

## Business Context
The application supports audit and assurance engagements across global clients,
enabling secure audit execution, compliance tracking, and reporting.

---

## Technology Stack
- Backend: ASP.NET Core Web API
- Frontend: Angular 11
- Database: Azure SQL
- Security: Azure Key Vault
- Cloud: Azure App Services

---

## Architecture Overview
- Clean / Layered Architecture
- Service & Repository pattern
- Modular Angular UI
- Secure cloud-based configuration
